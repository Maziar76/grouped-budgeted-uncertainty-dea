# Results

This directory is reserved for outputs generated by the reproducibility scripts.

The results include:
- Main GBU-DEA analysis outputs.
- Random-partition experiment results.
- Sensitivity analysis tables.
- Validation summaries.

Run the scripts in the `scripts/` directory to generate the corresponding results.

Generated files are not included in the repository. They can be reproduced locally using the source dataset and the instructions in the main README.
